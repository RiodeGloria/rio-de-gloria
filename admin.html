RÍO DE GLORIA

Administra nuestra página.

Edita todas las secciones de la página, sus textos, fotografías y enlaces. Solo una cuenta con permiso de escritura puede publicar.

La clave se usa únicamente para conectarte a GitHub. Permanece en memoria mientras esta pestaña esté abierta; debes ingresarla de nuevo al recargar o volver a entrar. No la envíes por chat.

Primera vez: crear mi clave de acceso
  1. Entra con la cuenta RiodeGloria a crear una clave en GitHub ↗.
  2. Escribe un nombre, por ejemplo Panel de fotos, y elige una fecha de vencimiento.
  3. En Resource owner, elige RiodeGloria. En Repository access, selecciona Only select repositories y marca solo rio-de-gloria.
  4. En los permisos del repositorio, agrega Contents: Read and write. Metadata de lectura se incluye automáticamente. No necesitas otros permisos.
  5. Presiona Generate token, copia la clave y pégala arriba. Guárdala en tu administrador de contraseñas para volver a entrar; puedes revocarla desde GitHub cuando quieras.

MINISTERIO CRISTIANO

Administrar página

Mis fotografías

Arrastra las fotos en computadora o usa «Mover a» en tu teléfono.

Los números indican la posición en la galería completa. Puedes seleccionar varias fotos JPG, PNG o WebP (máximo 20 por carga y 20 MB por foto). Se optimizan automáticamente para la página.

No hay fotografías para mostrar con este filtro.

Editar todas las secciones

Elige una sección y modifica sus textos, fotografías y enlaces. Los cambios se publican al pulsar Guardar y publicar. Para los enlaces utiliza https://, mailto: para correo o tel: para teléfono. Los enlaces internos existentes también se pueden conservar.

Horarios de cultos

Cambia los textos, las horas y la fotografía de cada tarjeta. Las horas corresponden a El Salvador.

Misión y visión

Escribe los textos oficiales de la iglesia. Si dejas un campo vacío, ese apartado no se mostrará.

Redes sociales

Pega el enlace completo de cada cuenta, comenzando con https://. Deja vacío lo que no quieras mostrar. Para WhatsApp puedes usar https://wa.me/503 seguido del número.

Sin cambios pendientesLos cambios solo aparecen en la página después de publicar.

¿Publicar los cambios?

Se actualizarán los apartados que hayas modificado en la página pública. GitHub puede tardar unos minutos en mostrar la nueva versión.
