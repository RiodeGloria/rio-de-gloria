La clave se usa únicamente para conectarte a GitHub. Permanece en memoria mientras esta pestaña esté abierta; debes ingresarla de nuevo al recargar o volver a entrar. No la envíes por chat.

Primera vez: crear mi clave de acceso
  1. Entra con la cuenta RiodeGloria a crear una clave en GitHub ↗.
  2. Escribe un nombre, por ejemplo Panel de fotos, y elige una fecha de vencimiento.
  3. En Resource owner, elige RiodeGloria. En Repository access, selecciona Only select repositories y marca solo rio-de-gloria.
  4. En los permisos del repositorio, agrega Contents: Read and write. Metadata de lectura se incluye automáticamente. No necesitas otros permisos.
  5. Presiona Generate token, copia la clave y pégala arriba. Guárdala en tu administrador de contraseñas para volver a entrar; puedes revocarla desde GitHub cuando quieras.
